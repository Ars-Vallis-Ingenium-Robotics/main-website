## qr.tips
- Test it with your phone before you print it.
- Logos need a little extra redundancy, so a code with a logo has more dots. That's normal.
- Print it at least 2 cm (about an inch) wide, bigger if people scan from far away.
- For codes on flyers you might change later, ask an officer for a dynamic code: it can be pointed somewhere new after it's printed.
